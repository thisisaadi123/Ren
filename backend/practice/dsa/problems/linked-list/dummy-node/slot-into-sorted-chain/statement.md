A chain of tags is kept in non-decreasing order as a linked list starting at `head`. A new tag with number `value` arrives.

Insert one new node holding `value` so the chain stays in non-decreasing order, and return the head of the updated chain.

{{examples}}

**Constraints**
- The chain has between `0` and `10⁵` nodes, in non-decreasing order.
- `-10⁶ ≤ node value, value ≤ 10⁶`
