A bracelet maker strings beads onto a thread, stored as a linked list from `head`. Every bead's value is its colour code, and a whole batch of colour `bad` turned out to be faulty.

Remove every bead whose value equals `bad`, keep the rest in their original order, and return the new head (the list may become empty).

{{examples}}

**Constraints**
- The list has between `0` and `10⁵` beads.
- `1 ≤ bead value ≤ 50`
- `1 ≤ bad ≤ 50`
