Two clubs keep their member numbers as linked lists, `first` and `second`, each in non-decreasing order. A list can contain the same number more than once (a member who signed up twice), and a member can belong to both clubs.

Build one list in increasing order that contains every member number from either club **exactly once**, and return its head.

{{examples}}

**Constraints**
- Each list has between `0` and `5 × 10⁴` nodes and is in non-decreasing order.
- `-10⁶ ≤ node value ≤ 10⁶`
