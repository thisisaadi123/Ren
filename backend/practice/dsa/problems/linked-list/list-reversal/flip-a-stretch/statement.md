A relay team's running order is a linked list starting at `head`, with positions numbered from `1`. The coach wants the runners in positions `left` through `right` (inclusive) to run in the opposite order, while everyone else keeps their place.

Reverse that stretch of the list and return the head.

{{examples}}

**Constraints**
- The list has `n` nodes, `1 ≤ n ≤ 10⁵`.
- `1 ≤ left ≤ right ≤ n`
- `-10⁵ ≤ node value ≤ 10⁵`
