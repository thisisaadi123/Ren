A necklace code is stored as a linked list of digits starting at `head`. The code is *mirrored* if reading the digits from the last node to the first gives exactly the same sequence as reading from first to last.

Return `true` if the list is mirrored and `false` otherwise. Aim for O(n) time and O(1) extra memory.

{{examples}}

**Constraints**
- The list has between `1` and `10⁵` nodes.
- `0 ≤ node value ≤ 9`
