A raffle printed `n + 1` tickets, but only the numbers `1` to `n` exist, so at least one number was printed twice. You've been told that exactly **one** number is repeated (it may appear two or more times); some other numbers may be missing entirely.

Given `tickets`, return the repeated number. Try to do it without changing the array and with only constant extra memory.

{{examples}}

**Constraints**
- `2 ≤ tickets.length = n + 1 ≤ 10⁵ + 1`
- `1 ≤ tickets[i] ≤ n`
- Exactly one value appears more than once.
