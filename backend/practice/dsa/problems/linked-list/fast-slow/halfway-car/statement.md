A parade of floats is a linked list starting at `head`. The marshal wants to stand at the halfway float and watch the rest of the parade go by.

Return the middle node of the list (and so the list from that node to the end). When the list has an even number of nodes, there are two middle nodes: return the **second** one.

{{examples}}

**Constraints**
- The list has between `1` and `10⁵` nodes.
- `-10⁵ ≤ node value ≤ 10⁵`
