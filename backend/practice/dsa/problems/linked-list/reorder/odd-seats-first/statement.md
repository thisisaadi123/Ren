Guests are seated along a table in the order of a linked list starting at `head`, and seats are numbered from `1`. The host wants everyone in an odd-numbered seat to be served first, then everyone in an even-numbered seat, each group in its current seating order.

Regroup the nodes so all nodes at odd positions come first, followed by all nodes at even positions, and return the head. Positions are about where a node sits, not its value. Use O(1) extra memory.

{{examples}}

**Constraints**
- The list has between `0` and `10⁵` nodes.
- `-10⁶ ≤ node value ≤ 10⁶`
