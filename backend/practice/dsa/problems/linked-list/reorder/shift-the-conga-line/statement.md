A conga line is a linked list starting at `head`. On every beat, the dancer at the very end of the line runs to the front. This happens `k` times.

Return the head of the line after `k` beats. `k` can be much larger than the number of dancers.

{{examples}}

**Constraints**
- The list has between `0` and `10⁵` nodes.
- `-10⁶ ≤ node value ≤ 10⁶`
- `0 ≤ k ≤ 2 × 10⁹`
