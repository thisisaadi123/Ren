An orchard logs the weight of every crate of apples in a binary search tree (for every node, lighter crates on its left side and heavier ones on its right; all weights distinct).

Return the total weight of all crates whose weight is between `low` and `high`, **inclusive**.

{{examples}}

**Constraints**
- The tree has between `1` and `10⁵` nodes and is a valid binary search tree with distinct values.
- `0 ≤ value ≤ 10⁹`
- `0 ≤ low ≤ high ≤ 10⁹`
