A library's shelf codes are given in increasing order as `codes`. Build a **binary search tree** that holds every code, where for every node the heights of its left and right subtrees differ by **at most one**.

Return the root. If several trees work, return any of them.

{{examples}}

**Constraints**
- `1 ≤ codes.length ≤ 10⁵`
- `-10⁹ ≤ codes[i] ≤ 10⁹`
- `codes` is strictly increasing.
