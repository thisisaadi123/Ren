A sorted linked list `head` holds distinct ticket numbers in increasing order. Turn it into a **binary search tree** with the same numbers in which, for every node, the heights of the left and right subtrees differ by **at most one**.

Return the root. If several trees work, return any of them.

{{examples}}

**Constraints**
- The list has `n` nodes, `1 ≤ n ≤ 10⁵`.
- `-10⁹ ≤ node value ≤ 10⁹`
- The values are strictly increasing.
