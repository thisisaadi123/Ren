A conference lists its `talks` as half-open intervals `[start, end)`. You can only be in one talk at a time, and you can walk straight from a talk ending at `t` into one starting at `t`.

Return the largest number of whole talks you can attend.

{{examples}}

**Constraints**
- `1 ≤ talks.length ≤ 10⁵`
- `0 ≤ start < end ≤ 10⁹`
