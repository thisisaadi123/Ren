A tree `root` has distinct values. Given two values `p` and `q`, which **may or may not be in the tree**, return the value of their lowest common ancestor: the deepest node with both `p` and `q` in its subtree (a node counts as in its own subtree). If `p` or `q` isn't in the tree, return `-1`.

{{examples}}

**Constraints**
- The tree has between `1` and `10⁴` nodes.
- `0 ≤ node value ≤ 10⁵`, all distinct.
- `0 ≤ p, q ≤ 10⁵` and `p ≠ q`.
