In a binary tree `root` with distinct values, find the **deepest nodes**: the ones farthest from the root. Return the value of the lowest node whose subtree contains **all** of them. If there's only one deepest node, that's the node itself.

{{examples}}

**Constraints**
- The tree has between `1` and `10⁴` nodes.
- `0 ≤ node value ≤ 10⁵`, all distinct.
