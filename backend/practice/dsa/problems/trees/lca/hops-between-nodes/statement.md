Rooms in a museum are connected like a binary tree `root`, with distinct room numbers. Moving between a room and one of its children takes one **hop**.

Return the fewest hops from room `p` to room `q`.

{{examples}}

**Constraints**
- The tree has between `1` and `10⁴` nodes.
- `0 ≤ node value ≤ 10⁵`, all distinct.
- `p` and `q` are in the tree (they may be the same room).
