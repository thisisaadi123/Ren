Water drips down a binary tree of pipes from the root. It escapes as soon as it reaches a **leaf** (a node with no children at all). Count the nodes on the shortest route from the root to any leaf, including both ends.

Return that count, or `0` for an empty tree.

**Constraints**
- The tree has between `0` and `10⁵` nodes.
- `-1000 ≤ value ≤ 1000`
