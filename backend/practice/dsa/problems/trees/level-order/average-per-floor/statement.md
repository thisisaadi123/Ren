An office tower's org chart is a binary tree: the root is on floor 0, its children on floor 1, and so on. Each node holds that employee's monthly sales figure.

Return the average figure of each floor, from floor 0 downwards. Answers within `10⁻⁵` (relative) of the exact averages are accepted.

**Constraints**
- The tree has between `1` and `10⁵` nodes.
- `-10⁹ ≤ value ≤ 10⁹`
