A window cleaner works down a binary tree of window ledges one floor at a time. On floor 0 (the root) and every even floor she moves **left to right**; on every odd floor she moves **right to left**.

Return the values in the order she cleans them, as one list per floor from the top. An empty tree gives an empty list.

{{examples}}

**Constraints**
- The tree has between `0` and `10⁵` nodes.
- `-1000 ≤ value ≤ 1000`
