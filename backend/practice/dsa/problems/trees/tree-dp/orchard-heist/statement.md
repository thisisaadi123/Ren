Apple trees in an orchard are connected by paths like the binary tree `root`, and each node's value is the number of apples on that tree. An alarm goes off if you pick two trees that are **directly connected** (a node and its child).

Return the most apples you can pick without setting off the alarm.

**Constraints**
- The tree has between `1` and `10⁴` nodes.
