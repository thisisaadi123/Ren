Every node of a binary tree holds one digit. Reading the digits from the root down to a leaf (a node with no children) spells a number, possibly with leading zeros; the number can be very long.

Return the sum of the numbers spelled by all root-to-leaf paths, modulo `10⁹ + 7`.

{{examples}}

**Constraints**
- The tree has between `1` and `10⁵` nodes.
- `0 ≤ value ≤ 9`
