Each node of a binary tree holds a number from `0` to `25`, standing for a letter (`0` is `a`, `1` is `b`, …, `25` is `z`). Starting at any leaf (a node with no children) and walking **up** to the root spells a word.

Return the alphabetically smallest such word. A word that is a prefix of another counts as smaller.

{{examples}}

**Constraints**
- The tree has between `1` and `10⁴` nodes.
- `0 ≤ value ≤ 25`
