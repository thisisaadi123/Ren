Each node of a binary tree holds a digit from `1` to `9`. A **trail** runs from the root down to a leaf (a node with no children). Call a trail a **mirror trail** when its digits read the same from the root down as from the leaf up, like `3 → 5 → 3` or `7`.

Return the number of mirror trails.

{{examples}}

**Constraints**
- The tree has between `1` and `10⁵` nodes.
- `1 ≤ value ≤ 9`
