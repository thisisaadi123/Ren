A **flip** chooses any node of a binary tree and swaps its left and right subtrees. Trees `a` and `b` are **flip-equivalent** if some number of flips (possibly none) turns `a` into `b`.

Every value in a tree is different. Return `true` if `a` and `b` are flip-equivalent.

{{examples}}

**Constraints**
- Each tree has between `0` and `10⁴` nodes.
- `0 ≤ node value ≤ 10⁵`, and the values in each tree are distinct.
