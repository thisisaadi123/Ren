A binary tree `root` holds integers. A **downward path** starts at any node and moves only from parents to children.

Return the **largest number of nodes** on a downward path whose values add up to exactly `target`, or `0` if there is none.

{{examples}}

**Constraints**
- The tree has between `1` and `10⁴` nodes.
- `-10⁵ ≤ node value ≤ 10⁵`
- `-10⁹ ≤ target ≤ 10⁹`
