A binary tree `root` holds integers, some of them negative. A **downward path** starts at any node and moves only from parents to children, ending at any node at or below its start.

Count the downward paths whose values add up to exactly `target`.

{{examples}}

**Constraints**
- The tree has between `1` and `10⁴` nodes.
- `-10⁵ ≤ node value ≤ 10⁵`
- `-10⁹ ≤ target ≤ 10⁹`
