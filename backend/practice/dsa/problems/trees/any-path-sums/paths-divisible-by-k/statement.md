A binary tree `root` holds non-negative integers. A **downward path** starts at any node and moves only from parents to children, ending at or below its start.

Count the downward paths whose sum is divisible by `k`.

{{examples}}

**Constraints**
- The tree has between `1` and `10⁴` nodes.
- `0 ≤ node value ≤ 10⁴`
- `1 ≤ k ≤ 10⁴`
