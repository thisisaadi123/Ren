A binary tree is a network of rooms joined by corridors (each parent–child link is one corridor). A walk may start at any room and end at any room, never using a corridor twice.

Return the largest number of corridors on any walk. A single room gives `0`.

{{examples}}

**Constraints**
- The tree has between `1` and `10⁵` rooms.
- `-1000 ≤ value ≤ 1000`
