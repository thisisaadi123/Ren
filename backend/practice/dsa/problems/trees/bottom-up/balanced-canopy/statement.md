A gardener calls a binary tree's canopy **balanced** when, at every node, the heights of its left and right branches differ by at most one. The height of an empty branch is `0`, and otherwise it is the number of nodes on its longest downward path.

Return `true` if the tree is balanced, and `false` otherwise. An empty tree is balanced.

{{examples}}

**Constraints**
- The tree has between `0` and `10⁵` nodes.
- `-1000 ≤ value ≤ 1000`
