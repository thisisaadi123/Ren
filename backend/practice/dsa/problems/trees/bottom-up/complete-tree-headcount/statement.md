A seating chart is a **complete** binary tree: every floor is full except possibly the last, and the last floor is filled from the left with no gaps.

Return the number of nodes. Try to do better than visiting every node: `O(log² n)` is possible.

{{examples}}

**Constraints**
- The tree has between `0` and `10⁵` nodes and is complete.
- `-1000 ≤ value ≤ 1000`
