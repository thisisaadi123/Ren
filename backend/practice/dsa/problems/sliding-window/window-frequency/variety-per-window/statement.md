A conveyor belt carries items, and `items[i]` is the type of the `i`-th item. A camera sees exactly `k` consecutive items at a time.

For every position of the camera, from the left end to the right end, return how many **different types** it sees.

{{examples}}

**Constraints**
- `1 ≤ k ≤ items.length ≤ 10⁵`
- `1 ≤ items[i] ≤ 10⁹`
