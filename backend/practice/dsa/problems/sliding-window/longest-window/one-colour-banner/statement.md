A banner is a row of coloured tiles written as the uppercase string `s`, one letter per colour. You may repaint **at most `k`** tiles, each to any colour.

Return the length of the longest run of consecutive tiles that can end up all the same colour.

{{examples}}

**Constraints**
- `1 ≤ s.length ≤ 10⁵`
- `s` has only uppercase English letters.
- `0 ≤ k ≤ s.length`
