A bus route has `fares[i]` as the price of the hop after stop `i`. A ride takes consecutive hops, paying for each one. With `budget` to spend, return the **largest number of consecutive hops** you can afford, or `0` if you can't afford even one.

{{examples}}

**Constraints**
- `1 ≤ fares.length ≤ 10⁵`
- `1 ≤ fares[i] ≤ 10⁴`
- `0 ≤ budget ≤ 10⁹`
