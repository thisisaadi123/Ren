A thermometer logs `readings`. A run of consecutive readings is **steady** when the difference between its highest and lowest reading is **at most `limit`**.

Return the length of the longest steady run.

{{examples}}

**Constraints**
- `1 ≤ readings.length ≤ 10⁵`
- `1 ≤ readings[i] ≤ 10⁹`
- `0 ≤ limit ≤ 10⁹`
