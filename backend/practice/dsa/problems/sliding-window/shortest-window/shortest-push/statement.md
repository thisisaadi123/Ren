A climber gains `gains[i]` metres during hour `i`, and every gain is positive. Return the **fewest consecutive hours** whose gains add up to at least `target`, or `0` if no stretch of hours gets there.

{{examples}}

**Constraints**
- `1 ≤ gains.length ≤ 10⁵`
- `1 ≤ gains[i] ≤ 10⁴`
- `1 ≤ target ≤ 10⁹`
