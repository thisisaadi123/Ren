Find the **shortest substring** of `s` that contains every character of `t`, counting repeats: if `t` has two `a`s, the substring needs at least two `a`s.

If several shortest substrings exist, return the one that starts **leftmost**. If no substring works, return `""`. Uppercase and lowercase letters are different characters.

{{examples}}

**Constraints**
- `1 ≤ s.length, t.length ≤ 10⁵`
- `s` and `t` have only English letters.
