A jar holds coins whose values are listed in `coins`; the same value can appear several times. You scoop out a handful: any selection of the coins, possibly none.

Two handfuls count as the same if they contain the same number of coins of every value. Return every **distinct** handful exactly once, with the coin values of each handful in **non-decreasing** order. The handfuls may be returned in any order.

{{examples}}

**Constraints**
- `1 ≤ coins.length ≤ 12`
- `-10 ≤ coins[i] ≤ 10`
