A pizzeria gives each of its toppings a distinct integer code, listed in `toppings`. A pizza may carry any set of these toppings, from none at all (plain cheese) up to every one of them.

Return every possible topping set. Write each set with its codes in **increasing** order. The sets themselves may be returned in any order.

{{examples}}

**Constraints**
- `1 ≤ toppings.length ≤ 10`
- `-10 ≤ toppings[i] ≤ 10`
- All values in `toppings` are distinct.
