A **calm word** of length `n` uses only the letters `a`, `b` and `c`, and no two neighbouring letters are equal. List all calm words of length `n` in alphabetical order and return the `k`-th one (1-indexed), or `""` if there are fewer than `k`.

{{examples}}

**Constraints**
- `1 ≤ n ≤ 30`
- `1 ≤ k ≤ 10⁹`
