A number puzzle is played on a `9 × 9` grid split into nine `3 × 3` boxes. Some cells already show a digit; the empty ones are `'.'`. Fill every empty cell with a digit `'1'` to `'9'` so that each row, each column and each `3 × 3` box contains every digit exactly once.

The puzzle is guaranteed to have exactly one solution. Return the completed grid.

{{examples}}

**Constraints**
- `board.length == 9` and `board[i].length == 9`
- `board[i][j]` is a digit `'1'` to `'9'` or `'.'`
- The given digits can be completed in exactly one way.
