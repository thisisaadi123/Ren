A town parade has floats numbered by the distinct integers in `floats`. The organisers want to see every possible running order before choosing one.

Return all orders in which the floats can drive past. Each order lists every float exactly once, and the orders may be returned in any sequence.

{{examples}}

**Constraints**
- `1 ≤ floats.length ≤ 7`
- `-10 ≤ floats[i] ≤ 10`
- All values in `floats` are distinct.
