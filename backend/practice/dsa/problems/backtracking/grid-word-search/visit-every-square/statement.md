A floor is a grid `floor` where `1` is the start, `2` is the end, `0` is an open square and `-1` is a wall. Count the walks from the start to the end that move up, down, left or right and step on **every** non-wall square exactly once.

{{examples}}

**Constraints**
- `1 ≤ rows × columns ≤ 20`
- There is exactly one start and exactly one end.
