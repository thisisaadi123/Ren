`n` people sit in a circle in seats `1` to `n`. Starting at seat `1`, count `k` people clockwise (counting the starting person as `1`); the `k`-th person leaves. Counting starts again from the next person still seated. This repeats until one person remains.

Return that person's seat number.

{{examples}}

**Constraints**
- `1 ≤ n ≤ 10⁶`
- `1 ≤ k ≤ 10⁹`
