`days` lists the days (as day numbers) on which a student practised, in no particular order and possibly with repeats.

Return the length of the longest streak of **consecutive** day numbers the student practised. For example, days `5, 6, 7` make a streak of 3.

{{examples}}

**Constraints**
- `0 ≤ days.length ≤ 10⁵`
- `-10⁹ ≤ days[i] ≤ 10⁹`
