Weights sit in a row. A **balance point** is an index `i` where the sum of the weights strictly to its left equals the sum strictly to its right. (An empty side sums to `0`.)

Return the leftmost balance point, or `-1` if there isn't one.

{{examples}}

**Constraints**
- `1 ≤ weights.length ≤ 10⁵`
- `-1000 ≤ weights[i] ≤ 1000`
