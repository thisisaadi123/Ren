A shelf has boxes labelled `1` to `n`. One label was printed twice, so one box carries a copy of another box's number and one number from `1` to `n` is missing.

Return `[duplicate, missing]`.

{{examples}}

**Constraints**
- `2 ≤ n ≤ 10⁵`, where `n = labels.length`
- `1 ≤ labels[i] ≤ n`
- Exactly one number appears twice and exactly one is missing.
