A street has buildings in a row, and `heights[i]` is the height of building `i`. Standing on building `i` and looking toward the end of the street, you see every building after it.

For each building, return the height of the tallest building **strictly after** it, or `-1` if it's the last one.

{{examples}}

**Constraints**
- `1 ≤ heights.length ≤ 10⁵`
- `1 ≤ heights[i] ≤ 10⁹`
