`code` is a **mirror number**: a string of digits that reads the same from both ends.

Rearrange its digits into the **smallest mirror number that is larger** than `code`, using every digit exactly as many times as it appears in `code`. Return it as a string, or `""` if no such mirror number exists.

{{examples}}

**Constraints**
- `1 ≤ code.length ≤ 10⁵`
- `code` contains only the digits `0`–`9`, reads the same from both ends, and doesn't start with `0`.
