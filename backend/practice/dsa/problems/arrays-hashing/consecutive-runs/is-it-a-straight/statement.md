A hand of `cards` is a **straight** if the cards can be rearranged so each card is exactly one more than the card before it. For example, `[7, 5, 6]` is a straight because it can become `5, 6, 7`.

Return `true` if the hand is a straight.

{{examples}}

**Constraints**
- `1 ≤ cards.length ≤ 10⁵`
- `-10⁹ ≤ cards[i] ≤ 10⁹`
