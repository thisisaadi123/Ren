Rearrange the characters of `s` so that the most frequent character comes first, then the next most frequent, and so on. All copies of a character stay together.

If two characters appear the same number of times, the one with the smaller character code comes first (so digits before uppercase letters, and uppercase before lowercase).

**Constraints**
- `1 ≤ s.length ≤ 10⁵`
- `s` contains only English letters and digits.
