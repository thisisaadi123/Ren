Every visitor to a conference gets a badge with a number on it. The printer occasionally jams and prints the same number twice.

Given the list of printed `badges`, return `true` if any number appears at least twice, and `false` if every number is different.

{{examples}}

**Constraints**
- `1 ≤ badges.length ≤ 10⁵`
- `-10⁹ ≤ badges[i] ≤ 10⁹`
