A row has seats numbered `0` to `n`, and `n` people have taken `n` different seats. `seats` lists the taken seat numbers, in no particular order.

Return the one seat number that's still free.

{{examples}}

**Constraints**
- `1 ≤ n ≤ 10⁵`, where `n = seats.length`
- The values are distinct and between `0` and `n`.
