A hotel has rooms `1` to `n`. The list `bookings` has `n` entries, each a room number. Every room is booked at most twice.

Return the rooms that were booked **twice**, in increasing order.

Try O(n) time and O(1) extra space, apart from the answer.

{{examples}}

**Constraints**
- `1 ≤ n ≤ 10⁵`, where `n = bookings.length`
- `1 ≤ bookings[i] ≤ n`
- Each room appears at most twice.
