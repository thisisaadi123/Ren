Count the **distinct** pairs of values `(x, y)` from `nums` such that `y - x == k`. A pair counts once no matter how many times its values appear, and `x` and `y` must come from different positions in the array.

{{examples}}

**Constraints**
- `1 ≤ nums.length ≤ 10⁵`
- `-10⁷ ≤ nums[i] ≤ 10⁷`
- `0 ≤ k ≤ 10⁷`
