A carousel has its seats in a circle, listed in `slots`. The carousel turns `k` steps to the right: every seat moves `k` places toward the end, and seats that pass the end wrap around to the front.

Return the seats in their new order. Try to do it in place with O(1) extra space.

{{examples}}

**Constraints**
- `1 ≤ slots.length ≤ 10⁵`
- `-10⁹ ≤ slots[i] ≤ 10⁹`
- `0 ≤ k ≤ 10⁹`
