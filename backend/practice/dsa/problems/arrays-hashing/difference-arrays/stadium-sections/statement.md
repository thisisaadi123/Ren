A stadium has `n` sections numbered `0` to `n - 1`. Each ticket group `[l, r, people]` spreads `people` fans into **every** section from `l` to `r`, inclusive.

Return how many fans end up in each section.

{{examples}}

**Constraints**
- `1 ≤ n ≤ 10⁵`
- `1 ≤ groups.length ≤ 10⁵`
- `0 ≤ l ≤ r < n`
- `1 ≤ people ≤ 10⁴`
