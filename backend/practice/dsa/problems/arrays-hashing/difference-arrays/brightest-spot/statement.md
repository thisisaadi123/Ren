Street lamps stand along an infinitely long street. Lamp `[position, reach]` lights every integer point from `position - reach` to `position + reach`, inclusive.

The brightness of a point is how many lamps light it. Return the **smallest** point with the highest brightness.

{{examples}}

**Constraints**
- `1 ≤ lamps.length ≤ 10⁵`
- `-10⁸ ≤ position ≤ 10⁸`
- `0 ≤ reach ≤ 10⁸`
