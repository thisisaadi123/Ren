Two words have the **same shape** if one can be turned into the other by consistently replacing letters, with different letters always mapping to different letters. For example `"moon"` and `"feet"` have the same shape, but `"moon"` and `"moan"` don't.

Count how many of the `words` have the same shape as `pattern`.

{{examples}}

**Constraints**
- `1 ≤ words.length ≤ 10⁴`
- `1 ≤ words[i].length, pattern.length ≤ 20`
- All strings contain only lowercase English letters.
