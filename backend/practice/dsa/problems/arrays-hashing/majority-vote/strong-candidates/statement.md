`votes` lists the option each voter picked. An option is **strong** if it got more than a third of all the votes, that is, more than `⌊n / 3⌋` of them.

Return every strong option in increasing order. Try to use O(1) extra space.

{{examples}}

**Constraints**
- `1 ≤ votes.length ≤ 10⁵`
- `-10⁹ ≤ votes[i] ≤ 10⁹`
