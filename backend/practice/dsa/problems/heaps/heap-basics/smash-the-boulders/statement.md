Each turn, take the two heaviest boulders and smash them together. If they weigh the same, both are destroyed. Otherwise the lighter one is destroyed and the heavier one now weighs the difference.

Return the weight of the last boulder left, or `0` if none are left.

{{examples}}

**Constraints**
- `1 ≤ boulders.length ≤ 10⁵`
- `1 ≤ boulders[i] ≤ 10⁹`
