Find every **different** triple of values `[a, b, c]` from `values`, taken from three different positions, with `a + b + c = 0`.

Write each triple in increasing order, and return the triples sorted. Two triples are the same if they have the same three numbers.

{{examples}}

**Constraints**
- `3 ≤ values.length ≤ 2000`
- `-10⁵ ≤ values[i] ≤ 10⁵`
