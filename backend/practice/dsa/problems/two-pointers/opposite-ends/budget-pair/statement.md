A shop lists its `prices` in increasing order. Exactly one pair of different items costs exactly `budget` together.

Return the positions `[i, j]` of that pair, with `i < j` (positions start at 0).

{{examples}}

**Constraints**
- `2 ≤ prices.length ≤ 10⁵`
- `-10⁹ ≤ prices[i] ≤ 10⁹`, sorted in increasing order
- Exactly one pair adds up to `budget`.
