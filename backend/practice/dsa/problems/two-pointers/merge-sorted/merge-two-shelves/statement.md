Two shelves hold books sorted by height: `left` and `right`, each in increasing order. Merge them into one shelf, still in increasing order, and return it.

{{examples}}

**Constraints**
- `0 ≤ left.length, right.length ≤ 10⁵`
- `left.length + right.length ≥ 1`
- `-10⁹ ≤ left[i], right[i] ≤ 10⁹`, each list sorted in increasing order
