A warehouse lists its stock `codes` in increasing order, with repeats. Remove the repeats so each code appears once, keeping increasing order, and return the result.

Try to do it in place with O(1) extra space.

{{examples}}

**Constraints**
- `1 ≤ codes.length ≤ 10⁵`
- `-10⁴ ≤ codes[i] ≤ 10⁴`, sorted in increasing order
