A shelf is a row of `slots`, where `0` means an empty slot. Slide every item to the left end, keeping the items in their original order, so all the empty slots end up on the right.

Return the shelf. Try to do it in place.

{{examples}}

**Constraints**
- `1 ≤ slots.length ≤ 10⁵`
- `-10⁹ ≤ slots[i] ≤ 10⁹`
