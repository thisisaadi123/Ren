A form stores its `cells` in a list, and the value `blank` marks an empty cell. Remove every blank cell, keeping the other cells in their original order, and return what's left.

Try to do it in place with O(1) extra space.

{{examples}}

**Constraints**
- `1 ≤ cells.length ≤ 10⁵`
- `0 ≤ cells[i], blank ≤ 100`
