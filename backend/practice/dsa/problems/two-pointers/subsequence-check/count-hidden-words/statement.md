A word is **hidden** in `text` if its letters appear in `text` in the same order, not necessarily next to each other.

Return how many of the `words` are hidden in `text`. Repeated words count each time they appear.

{{examples}}

**Constraints**
- `1 ≤ text.length ≤ 5 × 10⁴`
- `1 ≤ words.length ≤ 5000`
- `1 ≤ words[i].length ≤ 50`
- All strings have lowercase English letters.
