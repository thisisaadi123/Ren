You may delete any letters from `text`. Which words from `dictionary` can you make that way? Return the **longest** one. If several are equally long, return the one that comes first alphabetically. If none can be made, return an empty string.

**Constraints**
- `1 ≤ text.length ≤ 1000`
- `1 ≤ dictionary.length ≤ 1000`
- `1 ≤ dictionary[i].length ≤ 1000`
- All strings have lowercase English letters.
