A word is **hidden** in a text if you can find its letters in the text in the same order, though not necessarily next to each other. For example, `"ace"` is hidden in `"abcde"`.

Return `true` if `word` is hidden in `text`.

{{examples}}

**Constraints**
- `0 ≤ word.length ≤ 100`
- `0 ≤ text.length ≤ 10⁵`
- Both have lowercase English letters.
