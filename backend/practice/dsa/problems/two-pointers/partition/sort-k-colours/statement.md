`balls` holds balls of `k` colours, numbered `1` to `k`. Arrange them so the colours appear in increasing order.

Aim for O(n log k) time without counting colours into an extra array of size `k`.

{{examples}}

**Constraints**
- `1 ≤ balls.length ≤ 10⁵`
- `1 ≤ k ≤ balls.length`
- `1 ≤ balls[i] ≤ k`
