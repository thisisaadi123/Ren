A bag holds red, white and blue balls, written as `0`, `1` and `2` in `balls`. Arrange them so all the reds come first, then the whites, then the blues.

Do it in one pass without counting, using O(1) extra space.

{{examples}}

**Constraints**
- `1 ≤ balls.length ≤ 10⁵`
- `balls[i]` is `0`, `1` or `2`.
