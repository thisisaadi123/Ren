People stood in a line, then scattered. Each person remembers `[height, ahead]`: their height, and how many people **in front of them** were at least as tall as they are.

`people` lists these pairs in no particular order. Return the line from front to back as a list of the same pairs.

{{examples}}

**Constraints**
- `1 ≤ people.length ≤ 2000`
- `1 ≤ height ≤ 10⁶`
- `0 ≤ ahead < people.length`
- The pairs always describe some real line.
