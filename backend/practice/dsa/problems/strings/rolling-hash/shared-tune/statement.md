Two songs are written as strings of notes, `a` and `b`, one lowercase letter per note. Return the length of the longest run of notes that appears, in the same order and without gaps, in **both** songs. Return `0` if they share no note.

{{examples}}

**Constraints**
- `1 ≤ a.length, b.length ≤ 2 × 10⁴`
- `a` and `b` have only lowercase English letters.
