Pick two substrings of `s` that start at different positions but have the same length. They are **anagram twins** if one is a rearrangement of the other. For example, in `"abba"` the substrings `"ab"` (at index 0) and `"ba"` (at index 2) are twins.

Count the unordered pairs of anagram twins in `s`. Two equal substrings at different positions count as twins too.

{{examples}}

**Constraints**
- `1 ≤ s.length ≤ 500`
- `s` has only lowercase English letters.
