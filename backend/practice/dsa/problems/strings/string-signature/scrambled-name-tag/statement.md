At a party game the host takes a phrase `a`, scrambles its letters and shows you `b`. Two phrases are **scrambles** of each other if they use exactly the same letters the same number of times, once spaces are ignored and upper- and lowercase count as the same letter. For example, `"Dormitory"` and `"dirty room"` are scrambles.

Return `true` if `b` is a scramble of `a`, and `false` otherwise.

{{examples}}

**Constraints**
- `1 ≤ a.length, b.length ≤ 10⁵`
- `a` and `b` have English letters and spaces, and each has at least one letter.
