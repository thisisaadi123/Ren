A wallpaper strip `s` might be one short block pasted over and over. Return the length of the **shortest** block `u` such that `s` is exactly `u` repeated a whole number of times. If no shorter block works, the answer is `s.length`.

{{examples}}

**Constraints**
- `1 ≤ s.length ≤ 10⁵`
- `s` has only lowercase English letters.
