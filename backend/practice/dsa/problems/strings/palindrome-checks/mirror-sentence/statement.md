A sentence is a **mirror** if its letters and digits read the same forwards and backwards, once you ignore every other character (spaces, punctuation) and treat uppercase and lowercase letters as equal. For example, `"Step on no pets!"` is a mirror.

Return `true` if `text` is a mirror. Text with no letters or digits at all counts as a mirror.

{{examples}}

**Constraints**
- `1 ≤ text.length ≤ 2 × 10⁵`
- `text` has printable ASCII characters (codes 32 to 126).
