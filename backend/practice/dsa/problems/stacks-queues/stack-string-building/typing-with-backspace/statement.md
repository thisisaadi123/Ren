Two people type into identical text boxes. Their keystrokes are `a` and `b`, where every `#` is a **backspace**: it deletes the last character typed, if there is one.

Return `true` if both boxes show the same text at the end.

**Constraints**
- `1 ≤ a.length, b.length ≤ 10⁵`
- `a` and `b` have only lowercase English letters and `#`.
