An account's balance changes by `changes[i]` on day `i`, and changes can be negative. Return the length of the **shortest run of consecutive days** whose changes add up to **at least `target`**, or `-1` if no run does.

{{examples}}

**Constraints**
- `1 ≤ changes.length ≤ 10⁵`
- `-10⁵ ≤ changes[i] ≤ 10⁵`
- `1 ≤ target ≤ 10⁹`
