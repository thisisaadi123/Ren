A magician holds a deck with distinct numbers on the cards. Face down, the trick goes:

1. Reveal the top card and put it on the table.
2. If cards remain, move the new top card to the bottom of the deck.
3. Repeat until every card is on the table.

The magician wants the cards to be revealed in **increasing order**. Given the numbers on the cards, `cards`, return the order to stack them in, from top to bottom.

{{examples}}

**Constraints**
- `1 ≤ cards.length ≤ 10⁵`
- `1 ≤ cards[i] ≤ 10⁹`, all distinct.
