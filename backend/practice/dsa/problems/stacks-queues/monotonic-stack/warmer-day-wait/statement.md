A weather station logs one temperature per day in `temps`. For each day, count how many days you'd wait until a day that is **strictly warmer**. If no later day is warmer, the wait is `0`.

Return the waits, one per day.

{{examples}}

**Constraints**
- `1 ≤ temps.length ≤ 10⁵`
- `-100 ≤ temps[i] ≤ 100`
