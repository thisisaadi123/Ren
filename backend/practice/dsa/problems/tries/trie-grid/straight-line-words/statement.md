In a classic word-search puzzle, the board is a grid of letters given as the strings `board`, and a word is **hidden** if its letters appear in a straight line: across, down, diagonally, or any of those backwards (8 directions in total).

Return every word in `words` that is hidden in the board, in **alphabetical order**, each listed once.

{{examples}}

**Constraints**
- `1 ≤ rows, columns ≤ 50`
- `1 ≤ words.length ≤ 2000`, `1 ≤ words[i].length ≤ 50`
- Every string has only lowercase English letters. Words may repeat.
