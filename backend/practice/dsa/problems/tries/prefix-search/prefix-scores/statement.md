The **score** of a string `p` is the number of words in `words` that start with `p` (a word counts as starting with itself).

For each word, return the sum of the scores of all its non-empty prefixes.

{{examples}}

**Constraints**
- `1 ≤ words.length ≤ 2000`
- `1 ≤ words[i].length ≤ 100`
- Words have only lowercase English letters and may repeat.
