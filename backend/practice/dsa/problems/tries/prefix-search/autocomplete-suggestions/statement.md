A shop's search box suggests products as you type. After each letter of `typed`, it shows up to **three** products that start with what you've typed so far, choosing the alphabetically smallest ones.

Return one list of suggestions for each letter typed, in order.

{{examples}}

**Constraints**
- `1 ≤ products.length ≤ 1000`
- `1 ≤ products[i].length, typed.length ≤ 100`
- Every string has only lowercase English letters. Products may repeat.
