A gym's locker numbers are listed in increasing order, all different. Return the position of locker `target` in `lockers`, or `-1` if there's no such locker.

Your solution must run in O(log n) time.

{{examples}}

**Constraints**
- `1 ≤ lockers.length ≤ 10⁵`
- `-10⁹ ≤ lockers[i], target ≤ 10⁹`
- `lockers` is strictly increasing.
