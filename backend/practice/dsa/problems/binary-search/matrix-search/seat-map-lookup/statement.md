A theatre's seat numbers are stored in a grid. Each row is sorted in increasing order, and every row starts with a number bigger than the last number of the row before it.

Return `true` if seat number `target` is in the grid. Your solution must run in O(log(m·n)) time.

{{examples}}

**Constraints**
- `1 ≤ m, n ≤ 300`
- `-10⁹ ≤ rows[i][j], target ≤ 10⁹`
