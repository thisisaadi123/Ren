In an `n × n` `grid`, every row and every column is sorted in non-decreasing order. Return the `k`-th smallest value in the whole grid (counting duplicates; `k = 1` is the smallest).

Try to use less than O(n²) memory.

{{examples}}

**Constraints**
- `1 ≤ n ≤ 300`
- `-10⁹ ≤ grid[i][j] ≤ 10⁹`
- Rows and columns are sorted in non-decreasing order.
- `1 ≤ k ≤ n²`
