A teacher has a list of exam `scores` in no particular order. For each query `[lo, hi]`, return how many scores are between `lo` and `hi`, inclusive.

Answer the queries in order.

**Constraints**
- `1 ≤ scores.length, queries.length ≤ 10⁵`
- `-10⁹ ≤ scores[i] ≤ 10⁹`
- `-10⁹ ≤ lo ≤ hi ≤ 10⁹`
