A thermometer logged readings that were increasing, all different, and then the log was rotated so that it starts somewhere in the middle. Return the smallest reading.

Your solution must run in O(log n) time.

{{examples}}

**Constraints**
- `1 ≤ readings.length ≤ 10⁵`
- `-10⁹ ≤ readings[i] ≤ 10⁹`
- The values are distinct, and `readings` is a rotation of a sorted list.
