Choose a positive integer `d`. Divide every value in `loads` by `d`, rounding each result **up**, and add the results together.

Return the smallest `d` for which that total is at most `threshold`.

**Constraints**
- `1 ≤ loads.length ≤ 5 × 10⁴`
- `1 ≤ loads[i] ≤ 10⁶`
- `loads.length ≤ threshold ≤ 10⁶`
