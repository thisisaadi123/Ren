Several shuttles run at the same time, each on its own loop. Shuttle `i` takes `roundTime[i]` minutes per round and starts its next round immediately.

Return the minimum number of minutes after which the shuttles have finished at least `totalRounds` rounds between them.

{{examples}}

**Constraints**
- `1 ≤ roundTime.length ≤ 10⁵`
- `1 ≤ roundTime[i] ≤ 10⁷`
- `1 ≤ totalRounds ≤ 10⁷`
