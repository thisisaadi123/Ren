Two drummers keep time: one hits on every multiple of `a` (`a, 2a, 3a, …`), the other on every multiple of `b`. A beat is any positive whole number where at least one of them hits; when both hit at the same time it counts once.

Return the `n`-th beat. It can be huge, so return it modulo `10⁹ + 7`.

{{examples}}

**Constraints**
- `1 ≤ n ≤ 10⁹`
- `2 ≤ a, b ≤ 4 × 10⁴`
