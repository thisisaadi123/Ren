A row of flowers blooms over time: flower `i` blooms on day `bloom[i]` and stays in bloom. A bouquet uses `size` flowers that are **next to each other** in the row, and each flower can be used once.

Return the earliest day on which you can make `bouquets` bouquets, or `-1` if it's impossible.

{{examples}}

**Constraints**
- `1 ≤ bloom.length ≤ 10⁵`
- `1 ≤ bloom[i] ≤ 10⁹`
- `1 ≤ bouquets ≤ 10⁶`
- `1 ≤ size ≤ bloom.length`
