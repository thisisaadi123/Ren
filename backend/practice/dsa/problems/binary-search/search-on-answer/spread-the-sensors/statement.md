A road has possible sensor spots at positions `spots` (all different, in no particular order). You must install `sensors` sensors at different spots, spreading them out as much as possible.

Return the largest possible value of the **smallest** distance between any two installed sensors.

{{examples}}

**Constraints**
- `2 ≤ spots.length ≤ 10⁵`
- `1 ≤ spots[i] ≤ 10⁹`, all different
- `2 ≤ sensors ≤ spots.length`
