A times table has `rows` rows and `cols` columns; the cell in row `i`, column `j` (both counted from 1) holds `i × j`.

Return the `k`-th smallest number in the table (`k = 1` is the smallest; equal numbers in different cells count separately).

{{examples}}

**Constraints**
- `1 ≤ rows, cols ≤ 3 × 10⁴`
- `1 ≤ k ≤ rows × cols`
