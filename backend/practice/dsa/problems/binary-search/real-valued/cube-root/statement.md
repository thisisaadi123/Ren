A cube-shaped tank must hold exactly `volume` litres (a negative volume means the tank is measured below a reference level; just treat it as a number). Return the cube root of `volume`: the number `r` with `r × r × r = volume`.

Don't use a built-in power or cube-root function. Answers within `10⁻⁶` (relative, for large values) of the true root are accepted.

**Constraints**
- `-10⁹ ≤ volume ≤ 10⁹`
